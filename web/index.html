How it works

  1. Free quotes from the Telegraph node

    The node prices each request before payment. A bad input fails at no cost, and a run stops at $0.25.

  2. A second Telegraph miner on each hit

    A sanctions, registry, vessel or contract answer that is not clean goes to an independent miner. When the two disagree, the memo says REVIEW.

  3. The agent signs every memo

    Verify recomputes each signal's keccak256 hash on the node and checks the EIP-191 signature over the memo.

What does a diligence run cost?

Each check is $0.01 in test USDC on Sepolia. A run stops at $0.25 and the wallet at $2 a day.

How does the agent decide GO, REVIEW or STOP?

By a fixed rule in the code, never a model. A confirmed block is STOP; an unconfirmed hit or a missing critical answer is REVIEW.

Are queries to Telegraph private?

No. Requests and the paying wallet show on the public feed, so use public company and vessel names only.

How do I re-verify a Countersign memo?

Run npm run cs -- verify with the memo id. It fails if one byte of a signal or of the memo changed.

What if a Telegraph miner returns nothing useful?

The check counts as unknown, never as clear. An unknown critical check turns the memo to REVIEW.
